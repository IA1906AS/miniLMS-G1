Live Defense-in-Depth Inspector

Giám sát trực quan trạng thái vận hành của 8 lớp phòng thủ độc lập

Layer 1: AuthN & Crypto ACTIVE

Bcrypt (cost=10) & JWT HS256

Chống timing/enumeration, payload strictly sub, iat, exp.

Layer 2: Gatekeeper ACTIVE

Global Deny-by-Default

Mọi route chưa khai báo (VD: GET /debug) đều bị chặn 401.

Layer 3: Route Guards ACTIVE

@require_role(*roles)

Kiểm tra vai trò cấp route, ném 403 FORBIDDEN khi sai role.

Layer 4: Object-Level Auth ACTIVE

services.py (No Flask)

Tự kiểm tra quyền đối tượng độc lập cả khi route gỡ guard.

Layer 5: Strict Schema ACTIVE

schemas.py Type Safety

Chống boolean true/false, string "10", field thừa (400).

Layer 6: Fail-Closed ACTIVE

errors.py & Sanitization

JWT_SECRET >= 32 chars, chuẩn hóa {"error": "..."}.

Layer 7: Brute-Force ACTIVE

5 Failures / 15m Lock

Khóa tài khoản 429 ACCOUNT_LOCKED khi nhập sai liên tiếp.

Layer 8: Audit Logging ACTIVE

JSON Lines Audit Log

Ghi ts, actorId, action, oldScore, newScore. Không secret.
